# 심야 병동 캐릭터·커스터마이징 스펙

- 문서 버전: 2.2
- 기준일: 2026-07-29
- 상태: 세트 스킨 모델 구현 기준
- 코드 기준점: `src/shared/customization.ts`, `src/server/auth.ts`, `src/client/main.ts`, `src/client/game/ThreeGameView.ts`

## 1. 현재 구현 모델

- 캐릭터 카탈로그에는 `paperdoll`의 기본 콘셉트 이미지 12개만 둔다.
- 외형은 모자·옷·신발·장신구를 따로 합성하지 않는 **완성 세트 스킨**이다. 각 스킨은 해당 캐릭터의 앞·옆·뒤·이동·수면 프레임을 한 아틀라스로 보유해 홈, 상점, 커스텀, 인게임에서 같은 실루엣을 사용한다.
- 스킨은 기본 지급하지 않으며 해당 기본 캐릭터를 보유한 계정만 구매할 수 있다. `탐험가 모모`는 이벤트가 `100P`, 일반 완성 스킨은 `2,500P`, 여름 한정과 사이버펑크 프리미엄 스킨은 `5,000P`다. 일반 완성 스킨은 원본 특성의 1.5배를 기본값으로 사용하되, 프리미엄 스킨처럼 `traitOverride`가 있으면 문구와 수치를 그대로 적용한다. 실제 결제 상품 전환 시에도 이 구매 권한 모델을 유지한다.
- 완성형 스킨을 착용하면 그 스킨의 원본 캐릭터도 함께 착용한다. 경제형 스킨은 원본 캐릭터 특성을 별도로 중첩하지 않고 스킨 특성 하나로 대체한 뒤 침대 기본 생산량에 한 번만 합산한다. 따라서 Lv.1 침대와 서퍼 몽은 `침대 1 + 스킨 5 = 초당 6골드`이며, 몽의 기본 특성 1골드를 다시 더하지 않는다.
- `탐험가 모모`는 기본 토끼와 달리 침대 점유 전 이동속도 ×1.5라는 독자 능력을 사용한다.
- 상점과 커스텀은 `캐릭터 / 스킨 / 타일 / 포탑` 탭을 사용한다. 포탑 탭에는 현재 판매·보관 대상인 `서퍼 물총포`와 `파라솔 포탑`만 노출한다. 포탑 스킨은 해당 포탑군의 설치 건물 전체에 적용되며 계정의 포탑 스킨 로드아웃에 별도로 저장한다.
- 타일 스킨은 계정에 영구 귀속되며, 침대를 처음 점유한 생존자의 장착 타일이 해당 방 전체에 적용된다. `파도 타일`과 `모래사장 타일`은 각각 1,000P다. 기본 병동 타일은 상품 카드로 노출하지 않고, 장착한 타일 스킨을 해제했을 때 자동으로 적용되는 기본 상태로만 유지한다.
- `서퍼 물총포`는 기본 수호 포탑용 1,500P 스킨이다. 레벨별 완성 이미지를 사용하고, 탄환은 물줄기와 착탄 물보라로 표현한다. 전투 능력치는 기본 수호 포탑과 동일하다.
- `파라솔 포탑`은 기본 수호 포탑용 1,500P 스킨이다. 완전히 접힌 파라솔에서 시작해 점차 펼쳐지고, 2단·3단 캐노피와 구조대 전망대·구명환 외곽 구조로 성장한다. 별도 총열은 추가하지 않고 파라솔 자체의 위 꼭지점을 발사 지점으로 사용한다.

## 2. 목표

1. 플레이어는 실사형 귀신과 대비되는 작고 귀여운 2D 탑다운 생존자 스프라이트로 보인다.
2. 다른 게임의 캐릭터를 복제하지 않고 토끼·고양이·강아지·곰·여우·햄스터를 모티브로 한 독자적인 투명 PNG 세트 스킨을 만든다.
3. 승리 → 커스텀 포인트 획득 → 아이템 구매 또는 등급 해금 → 착용 → 다음 게임에서 표현되는 성장 순환을 만든다.
4. 기본 토끼를 제외한 생존자 캐릭터는 한 가지 서버 판정 특성을 가진다. 스킨은 해당 캐릭터의 특성을 기본적으로 1.5배 적용하거나, `traitOverride`로 독자 능력을 사용한다.

## 3. 화면 흐름

```text
게임 홈
├─ 플레이 방식 모달 → 혼자하기/친구랑하기/랭크전 선택
├─ 상점 → 꾸미기 영구 구매·전술 보급 수량 구매
└─ 내 보관함 → 보유한 캐릭터/스킨/타일/포탑 스킨 착용 또는 해제
```

- 게임 홈 하단은 `상점 / 스테이지 / 커스텀`의 세 메뉴로 고정한다. 스테이지 화면에는 플레이 방식 선택 상자와 주 `스테이지 시작` 버튼을 나란히 둔다.
- 플레이 방식 상자는 네이티브 셀렉트 대신 혼자하기·친구랑하기·랭크전 설명과 초대 코드 참여를 포함한 모달을 연다. 스테이지 메뉴는 현재 일반 모드에서 해금된 스테이지 선택 모달을 열고, 랭크전에서는 활성 계약 목록을 연다.
- 플레이 선택 화면은 거대한 포스터와 번호 장식을 제거하고 혼자하기, 친구랑하기, 초대 참가, 랭크전을 명확한 기능 영역으로 나눈다.
- 상점은 `꾸미기`와 `전술 보급`을 분리한다. 꾸미기는 미보유 외형까지 전부 보여 주고 포인트로 영구 구매하며, 구매 후 자동 착용하지 않고 커스텀 탭에서 선택한다. 전술 보급은 수량 단위로 구매하는 비영구 소모품이며, 상세 규칙과 카탈로그는 `docs/spec/shop-consumables.md`를 따른다.
- 내 보관함은 기본 지급, 포인트 구매 완료, 달성한 등급 보상을 포함해 현재 계정이 사용할 수 있는 보유품만 보여 준다. 구매 버튼은 표시하지 않고 착용만 처리한다.
- 내 보관함의 화면 제목은 캐릭터·스킨·타일·포탑 탭 모두 `내 보관함`으로 고정한다. 포탑 스킨을 하나도 보유하지 않은 경우 포탑 탭의 미리보기에는 판매 상품을 대신 노출하지 않고 기본 수호 포탑 Lv.1을 표시한다.
- 두 화면은 같은 2D 프리뷰와 `앞/옆/뒤` 버튼을 사용한다. 진입 시 `앞`이 기본 선택이며, 선택한 캐릭터 또는 스킨의 프레임만 교체한다.
- 카드를 누르면 프리뷰만 임시 전환하고 구매·착용 API는 별도 버튼을 누를 때만 호출한다. 스킨을 해제하면 기본 캐릭터 프레임으로 즉시 돌아간다.
- 모바일 검증 해상도는 세로 390×844와 가로 844×390이다. 세로에서는 피팅룸과 스크롤 가능한 보유품·상점 목록을 상하로 배치한다.

## 4. 캐릭터와 세트 스킨

| 구분   | 기본 지급/구매                                                | 표현 방식                                       |
| ------ | ------------------------------------------------------------- | ----------------------------------------------- |
| 캐릭터 | 토끼 모모만 기본 지급, 나머지는 포인트 구매                   | `paperdoll` 기본 콘셉트와 기본 이동·수면 프레임 |
| 스킨   | 모두 별도 구매, 탐험가 모모 100P·일반 2,500P·프리미엄 5,000P | 캐릭터별 완성형 앞·옆·뒤·이동·수면 프레임       |
| 타일   | 파도 타일·모래사장 타일 각 1,000P                              | 침대 점유 시 해당 방 바닥 전체를 교체            |
| 포탑   | 서퍼 물총포·파라솔 포탑 각 1,500P                              | 건설 시 장착 외형을 기록하고 레벨별 이미지를 표시 |

개별 모자·옷·장신구·신발의 런타임 합성은 사용하지 않는다. 포탑 스킨도 부품을 합성하지 않고 레벨마다 준비된 완성 이미지 한 장을 사용한다.

시즌 순위로 지급하는 한정 스킨도 같은 완성형 세트 구조를 사용한다. 한정 스킨의 고유 특성은 혼자하기·친구랑하기에서 적용하되 랭크전에서는 계약 표준 능력치로 보정하고 외형만 유지한다.

### 생존자 고유 특성

| 캐릭터        | 특성                                              |
| ------------- | ------------------------------------------------- |
| 달고양이 루루 | 모든 포탑 공격속도 +15%                           |
| 구름강아지 몽 | 침대 점유 중 초당 골드 +1                         |
| 도토리곰 밤이 | 모든 포탑 피해 +10%                               |
| 별여우 초롱   | 한 판 램프 사용 횟수 +1                           |
| 유령햄스터 콩 | 처음 건설하는 수호 포탑이 Lv.2로 시작 (스킨 Lv.3) |
| 늪악어 크로크 | 모든 포탑 피해 +35%                               |
| 달오리 꽥     | 침대 점유 중 초당 전력 +1 (달빛 정찰 꽥 +1.5)     |
| 달호랑이 라온 | 모든 수호 포탑 사거리 +1칸                        |
| 별공룡 라그   | 모든 포탑 공격속도 +40%                           |
| 달원숭이 몽키 | 한 판 램프 사용 횟수 +2                           |
| 요새고릴라 콩 | 문 최대 HP 50%의 이중문 방어막 (스킨 75%)          |

전용 스킨은 원본 특성을 중복해서 더하지 않는다. `서퍼 몽`은 초당 골드 +5, `해변 구조대 라온`은 수호 포탑 사거리 +2칸과 공격속도 +20%, 일반 `붉은 번개 라온` 스킨은 사거리 +1칸과 공격속도 +5%를 적용한다. `네온 라이더 루루`는 모든 포탑의 공격 간격을 절반으로 줄여 공격속도를 2배로 만들고, `사이버 드라이버 콩`은 첫 포탑만이 아니라 새로 설치하는 모든 수호·연사·아크·황금 포탑을 Lv.5로 시작한다.

## 5. 해금 방식

- `starter`: 계정 생성 즉시 사용 가능하다.
- `points`: 표시된 커스텀 포인트를 지불해 계정에 영구 귀속한다.
- 완성 스킨은 모두 `points` 상품이다. 기본 캐릭터가 없으면 상점에서 `캐릭터 구매 필요`로 비활성화한다.
- 기존 카탈로그의 `rank` 조건은 시즌 랭크가 아니라 혼자하기·친구랑하기 일반 진행 등급을 뜻한다. 둘 중 높은 진행 등급이 요구 등급 이상이면 자동 해금한다.
- 시즌 순위 한정 스킨과 칭호는 랭크 시즌 보상 지급 기록으로 해금하며 포인트로 재구매할 수 없다.
- 포인트 구매 아이템과 등급 아이템을 동시에 요구하지 않는다.
- 이미 구매한 아이템 재구매와 보유하지 않은 포인트 아이템 착용은 서버가 거절한다.

## 6. 포인트 경제

듀토리얼을 제외한 승리 판은 결과 화면에서 전리품을 수령해야 아래 포인트를
지급한다. 혼자하기, 친구랑하기, 랭크전 모두 같은 수령 흐름을 사용한다.

```text
승리 포인트 = 80 + min(420, 스테이지 전역 인덱스 × 4)
패배 포인트 = 0
```

- 쉬움 1은 80포인트, 노말 5는 100포인트, 에픽 20은 320포인트, 레전더리 후반은 최대 500포인트다.
- 같은 `matchId + accountId` 결과는 한 번만 기록되므로 재연결이나 재전송으로 중복 지급되지 않는다.
- 기본 캐릭터 가격은 각 카탈로그의 포인트 가격을 사용한다. 세트 스킨은 `탐험가 모모` 100P, 일반 스킨 2,500P, `서퍼 몽`·`해변 구조대 라온`·`네온 라이더 루루`·`사이버 드라이버 콩`은 각각 5,000P다. `파도 타일`·`모래사장 타일`·`네온 회로 타일`은 각 1,000P, `서퍼 물총포`·`파라솔 포탑`·`네온 레이저포`는 각 1,500P다.
- 커스텀 포인트는 유료 재화가 아니며 현재 버전에서는 게임 클리어로만 획득한다.
- `전리품 수령`은 기본 포인트를 지급하고 홈으로 이동한다.
- `2배 수령`은 보상형 광고 완료 뒤 기본 포인트의 2배를 지급하고 홈으로
  이동한다.
- 광고 제거 이용자는 일반 수령 버튼을 숨기고, 광고 없는 `2배 전리품 수령`
  버튼 하나를 전체 폭으로 표시한다.
- 포인트 지급은 `matchId + accountId` 기준 서버 멱등 처리로 중복 탭과 재접속
  중복 수령을 막는다.

## 7. D1 저장 구조

| 테이블                    | 주요 필드                                                        | 설명                                    |
| ------------------------- | ---------------------------------------------------------------- | --------------------------------------- |
| `account_customization`   | `account_id`, `custom_points`, `appearance`                      | 지갑과 현재 착용 JSON                   |
| `account_cosmetics`       | `account_id`, `item_id`, `purchased_at`                          | 포인트로 영구 구매한 아이템             |
| `account_turret_loadouts` | `account_id`, `skins`                                            | 포탑군별 현재 장착 스킨 JSON             |
| `cosmetic_catalog`        | `id`, `slot`, `point_price`, `trait_multiplier`, `display_order` | 이미지 이외의 상품·능력·판매 메타데이터 |

- 기존 `accounts` 테이블은 변경하지 않는다.
- 두 테이블은 계정 삭제 시 함께 삭제되도록 외래키 `ON DELETE CASCADE`를 사용한다.
- 기본 아이템과 등급 해금 아이템은 구매 행을 만들지 않고 카탈로그 규칙으로 판정한다.
- 구매, 착용, 포인트 지급은 서버 권한이며 클라이언트가 잔액이나 보유 목록을 직접 결정하지 않는다.
- `0016_cosmetic_catalog.sql`은 현재 코드 카탈로그의 캐릭터 12종과 완성형 스킨 전체를 D1에 이관한다. `0017_wave_tile_skin.sql`은 카탈로그 슬롯을 `tile`까지 확장하고 기본 병동 타일과 파도 타일 상품을 추가한다. `0018_surfer_water_turret_skin.sql`은 서퍼 물총포를, `0019_lifeguard_beach_cosmetics.sql`은 모래사장 타일과 파라솔 포탑을, `0024_cyberpunk_premium_skins.sql`은 사이버펑크 프리미엄 스킨 2종을, `0025_cyberpunk_theme_cosmetics.sql`은 네온 회로 타일과 네온 레이저포의 가격·연출·자산 메타데이터를 추가한다. 이미지 파일은 정적 자산 경로에 유지하고 DB에는 `asset_directory`만 저장한다.

### 파도 타일 점유 연출

- 서버는 방마다 `tileSkinId`, `tileSkinActivatedAt`을 저장한다. 첫 침대 점유자가 파도 타일을 장착한 경우에만 해당 방에 기록하며 두 번째 입장자가 덮어쓰지 않는다.
- 클라이언트는 방 왼쪽 끝에서 오른쪽 끝으로 반투명 파도 띠를 이동시키고, 파도 열이 닿은 타일부터 순서대로 세로축 플립 모션을 재생한 뒤 파도 타일 텍스처를 고정한다.
- 재접속 시 전환 시간이 이미 지났다면 애니메이션을 반복하지 않고 완성된 파도 타일을 즉시 복원한다.
- 타일 스킨은 방 바닥만 변경하며 복도·벽·문·침대·설치 건물의 스킨과 충돌하지 않는다.
- 타일 스킨 메시를 기본 바닥 위에 덮는 장식 레이어로 올리지 않는다. 방별 기본 바닥 인스턴스를 숨기고 같은 바닥 높이의 스킨 타일로 교체해 `＋` 설치 표시, 침대, 문, 설비 이미지가 항상 위에 보이게 한다.
- 첫 단계에서는 기존 동기 렌더와 게임 규칙의 안전성을 위해 공유 TypeScript 카탈로그도 함께 유지한다. 이후 카탈로그 API를 붙일 때 D1의 가격·판매 기간·노출 순서를 상업 정보의 기준으로 삼고, 서버 게임 특성 키는 코드의 허용 목록과 교차 검증한다.

### 모래사장 타일 점유 연출

- 침대를 점유하면 방 중앙에 세 겹의 모래 소용돌이를 만들고 중심에서 먼 타일일수록 늦게 나타나도록 지연 시간을 계산한다.
- 소용돌이가 회전하며 사라지는 동안 각 타일은 중심부터 바깥쪽 순서로 회전·상승한 뒤 원래 바닥 높이에 고정된다.
- 파도 타일과 마찬가지로 기본 바닥을 숨기고 같은 바닥 높이에 대체 메시를 배치하므로 설치 표시와 건물은 항상 타일보다 위에 보인다.

### 서퍼 물총포 표현

- 자산은 `public/assets/turret-skins/skin-surfer-water-blaster/level-01.png`부터 `level-15.png`까지 512px 정사각 투명 PNG로 저장한다.
- 각 레벨 이미지는 같은 타일 중앙과 하단 방향 포열 앵커를 공유한다. 크기만 키우지 않고 저장통, 펌프, 압력계, 구조대 장식과 대왕 물총 실루엣을 단계적으로 추가한다.
- 수호 포탑은 평소 문을 향하고 귀신이 사거리 안에 들어오면 이미지 피벗 전체가 귀신을 향해 회전한다.
- 서버는 발사 이벤트에 건설 당시 기록한 `skinId`를 포함한다. 클라이언트는 서퍼 물총포일 때만 기본 탄환 대신 청록색 물줄기와 착탄 물보라를 재생한다.
- 장착 스킨은 새로 건설한 수호 포탑에 저장되며, 재접속과 멀티플레이에서도 건물 상태의 `skinId`로 동일한 레벨 이미지를 복원한다.
- 인게임 설치 모달의 수호 포탑 카드도 현재 장착한 포탑 스킨의 Lv.1 이미지를 사용한다. 스킨을 장착하지 않았을 때만 기본 병동형 Lv.1을 표시한다.

### 파라솔 포탑 표현

- 자산은 `public/assets/turret-skins/skin-lifeguard-parasol/level-01.png`부터 `level-15.png`까지 512px 정사각 투명 PNG로 저장한다.
- Lv.1~6은 `완전 접힘 → 느슨해짐 → 1/4 개방 → 반개방 → 거의 개방 → 완전 개방`, Lv.7~15는 다단 캐노피와 구조대 지휘소 구조가 커지는 실루엣 변화로 구분한다.
- 호루라기·선글라스·호랑이 문양은 테마를 보조하지만 레벨 차이를 장식 개수로만 만들지 않는다.
- 런타임에서는 포탑 이미지 피벗 전체가 문 또는 귀신을 향해 회전하며 파라솔 자체의 위 꼭지점이 발사 방향을 나타낸다.

### 사이버펑크 테마 표현

- `네온 회로 타일`은 어두운 보라색 금속 패널과 청록·핑크 회로를 사용하되, 중앙은 설치 건물과 `＋` 표시를 가리지 않도록 낮은 명도로 유지한다.
- 침대를 점유하면 방 중앙에 저폴리 네온 빌딩 군집이 솟아오른다. 빌딩이 옆으로 무너지며 청록·핑크 충격파가 퍼지고, 중심에서 바깥쪽 순서로 타일이 뒤집혀 최종 회로 타일이 된다.
- 빌딩은 최대 5개 저폴리 박스와 2개 링만 사용하고 전환 완료 즉시 지오메트리와 재질을 해제한다. 지속 파티클이나 매 프레임 객체 생성은 사용하지 않는다.
- `네온 레이저포`는 `public/assets/turret-skins/skin-cyberpunk-laser/level-01.png`부터 `level-15.png`까지 같은 512px 중심축을 공유한다. 권총부터 기관권총·카빈·라이플·레일건을 거쳐 거대 레이저 요새로 실루엣이 성장한다.
- 타일과 구별되도록 포탑 몸체는 밝은 아이보리·건메탈 비중을 높이고, 핑크·보라·청록 네온은 발광 회로와 에너지 코어에만 사용한다.
- 공격 시 기본 탄환 대신 굵은 청록 코어와 핑크 외곽광으로 된 짧은 레이저를 표시한다. 레이저와 착탄 링은 각각 최대 16개·기존 공용 한도 안에서 재사용하며 저품질 모드에서는 외곽광을 생략한다.

### 구매·착용 처리 상태

- 외형·타일·전술 보급 구매와 내 보관함의 착용·해제 요청 동안 앱 전체에 반투명 로딩 오버레이를 표시한다.
- 오버레이는 현재 화면을 약하게 비치게 하되 모든 중복 입력을 차단하고, 처리 대상 이름과 `구매 중 / 착용 중 / 착용 해제 중` 상태를 표시한다.
- 성공·실패와 관계없이 요청이 끝나면 오버레이를 제거한다. 서버 응답 전에는 카드 목록을 다시 그리거나 잔액·보유 상태를 클라이언트에서 먼저 변경하지 않는다.

## 8. 2D 캐릭터·스킨 원칙

- 기본 캐릭터와 스킨은 362px 정사각 투명 셀의 같은 중심 앵커를 공유한다. 앞·옆·뒤·이동·수면 모든 프레임은 이 앵커를 보존해야 한다.
- 이동은 몸통 흔들기나 좌우 보간 없이 걷기 프레임만 느리게 교대한다. 홈 프리뷰는 정면 보행 프레임을 사용한다.
- 수면은 아래를 보는 서기 프레임이 아니라 옆으로 누운 별도 `sleep.png`를 사용한다.
- 프리뷰는 캐릭터의 실루엣이 잘리지 않도록 전신 중앙을 기준으로 배치하고, 꼬리가 있는 여우 등은 몸통 중심을 앵커로 삼는다.
- 스킨은 본체에 레이어를 덧씌우지 않는다. 각 완성 스킨 프레임을 통째로 표시해 홈·상점·커스텀·인게임에서 모자·옷·신발이 어긋나는 문제가 생기지 않게 한다.
- `서퍼 몽`은 걷기 대신 보드 아래 물결과 보드 기울기만 바뀌는 활주 프레임을 사용한다. 몸통 중심과 보드 바닥 기준선은 모든 방향·프레임에서 고정한다.
- `해변 구조대 라온`은 걷기 대신 달리기 프레임을 사용하며 매 발걸음마다 발 아래 물보라가 바뀐다. 빨간 구조대 모자, 모자에 걸친 검정 선글라스, 구명 튜브와 호루라기는 모든 방향 프레임에 포함한다.
- `네온 라이더 루루`는 정지 시 한 손을 주머니에 넣고 네온 라이플을 어깨에 얹는다. 이동 시 양손으로 균형을 잡고 인라인스케이트를 타며, 발 아래 별과 네온 선은 별도 파티클을 대량 생성하지 않고 이동 프레임에 포함해 성능을 보존한다.
- `사이버 드라이버 콩`은 후드 아래 눈이 보이고 보라색 권총과 운전대를 든 스포츠카 탑승형 완성 스프라이트다. 이동 방향에 맞는 차체 프레임을 사용하며 바퀴 무지개빛과 배기 불꽃도 이동 프레임에 포함한다.
- 외형 상점의 스킨 목록에서는 `네온 라이더 루루`, `사이버 드라이버 콩`, `서퍼 몽`, `해변 구조대 라온` 순으로 프리미엄 스킨을 먼저 배치한다.
- 상점과 내 보관함의 서퍼 몽 카드는 전용 파도 배경, 하늘빛 프리미엄 테두리, `NEW` 뱃지와 반짝임 효과를 사용한다.
- 서퍼 몽을 미리 볼 때는 전용 파도 배경을 미리보기 영역 전체에 표시하고 이동 아틀라스를 재생한다.
- 서퍼 몽을 보유하지 않은 플레이어가 앱 세션에서 처음 홈에 들어오면 여름 출시 팝업을 한 번 표시한다. `구매하러 가기`는 외형 상점의 스킨 탭을 열고 서퍼 몽 카드와 미리보기를 선택한다.
- 홈의 여름 출시 이벤트는 `서퍼 몽`과 `해변 구조대 라온`을 하나의 통합 캠페인 이미지와 팝업으로 표시한다. `스킨 보러 가기`는 스킨 상점을 열어 두 여름 한정 카드가 목록 첫 줄에서 함께 보이게 한다.
- 사이버펑크 출시 이벤트는 루루와 콩이 네온 도시에서 함께 달리는 통합 이미지로 표시한다. `스킨 보러 가기`는 스킨 상점을 열고 `네온 라이더 루루`를 즉시 선택한다.
- 홈 출시 이벤트는 여름·사이버펑크 캠페인을 좌우 화살표와 페이지 점이 있는 슬라이드로 보여 준다. 각 캠페인의 `다시 보지 않기`는 서로 다른 로컬 저장 키를 사용하므로 하나만 숨긴 경우 남은 캠페인만 계속 표시하고, 둘을 모두 숨기거나 모두 보유했을 때만 팝업을 열지 않는다.
- `다시 보지 않기`는 브라우저 로컬 저장소에 해당 캠페인의 숨김 상태를 영구 저장한다. 단순히 구매 화면으로 이동한 경우에는 다음 앱 실행 때 다시 표시할 수 있다.

## 9. 1차 완료 기준

- 신규·기존 계정이 커스텀 화면에 진입할 수 있다.
- 승리 전리품을 수령하면 포인트가 서버에서 한 번만 지급된다.
- 캐릭터와 세트 스킨 구매·착용 상태가 D1에 저장된다.
- 멀티플레이 입장 시 서버가 검증한 착용 상태가 `PlayerState`에 포함된다.
- 로컬 플레이어·다른 플레이어·봇은 서버가 검증한 캐릭터 또는 세트 스킨 2D 프레임으로 표시된다.
- 미보유 캐릭터·스킨도 잔액 변화 없이 프리뷰할 수 있고, 앞·옆·뒤 버튼은 같은 앵커의 해당 방향 프레임을 표시한다.
- 모바일 390×844와 844×390에서 게임 홈, 플레이 방식 모달, 상점, 커스텀 화면이 겹치지 않는다.
