# 심야 병동 비주얼·모바일 UX 스펙

- 문서 버전: 4.4
- 기준일: 2026-07-24
- 상태: 현재 클라이언트 구현 기준
- 코드 기준점: `src/client/styles.css`, `src/client/game/ThreeGameView.ts`, `src/shared/stageThemes.ts`, `public/assets/sprites`

이 문서는 게임 화면을 시네마틱 호러와 수직 탑다운 2D 조작 구조로 통일하기 위한 기준이다. 로비·티저는 프로젝트 전용 생성 이미지를 사용한다. 전장·설비·상호작용 효과는 Three.js 직교 카메라를 유지하고, 생존자와 본체 귀신은 같은 시점의 2.5D 투명 스프라이트로 렌더링한다.

## 1. 디자인 방향

1. 배경은 검정 한 색이 아니라 짙은 남색 레이어와 은은한 청록·보라 조명으로 깊이를 만든다.
2. 전장은 하늘에서 수직으로 내려다보는 직교 카메라를 사용해 방 안 타일이 중첩 없이 모두 보이게 한다.
3. 중요한 조작은 밝은 청록, 보조 조작은 라벤더, 비용·보상은 금색, 위험은 분홍빛 적색으로 일관되게 표시한다.
4. 정보량이 많은 HUD는 불투명 상자가 아니라 반투명 유리 패널로 구성해 전장을 가리지 않는다.
5. 장식보다 가독성을 우선한다. 색상만으로 상태를 구분하지 않고 아이콘, 게이지, 텍스트를 함께 사용한다.

## 3. 인터페이스 컴포넌트

- HUD와 모달은 16~26px 둥근 모서리, 얇은 밝은 테두리, 16~24px 배경 블러를 사용한다.
- 상단 자원 수치는 아이콘이 포함된 작은 캡슐 칩으로 표시한다.
- 우측 행동 버튼은 오래된 원형 게임패드 형태 대신 둥근 사각형 또는 캡슐 형태로 만든다.
- 주 행동 버튼은 금색, 가방은 반투명 남색, 현재 선택 상태는 청록 테두리로 구분한다. 선택 해제는 패널 바깥 터치로 처리해 별도 취소 버튼을 두지 않는다.
- 설치 모달의 설비 설명은 "매초 전기를 얻습니다"처럼 한눈에 행동을 알 수 있는 짧은 문장으로 쓰며, 카드에서 말줄임표로 자르지 않고 줄바꿈으로 모두 표시한다.
- 홈의 스테이지 선택기는 노치·상단 유틸리티 버튼 아래 안전 영역에 놓고, 승리 후 계정 진행도가 저장되면 새로 해금된 가장 높은 스테이지를 자동 선택한다.
- 스테이지 선택 모달은 화면 높이를 넘으면 모달 내부만 세로 스크롤한다. iOS에서도 바깥 배경이 아니라 스테이지 목록을 한 손가락으로 끝까지 스크롤할 수 있어야 한다.
- 건설 패널은 설비 아이콘, 이름, 현재/다음 레벨, 효과, 골드·전력 비용을 한 카드 안에서 바로 읽을 수 있게 한다.
- 연결·재접속·게임 단계는 상단의 작은 상태 칩으로 표시하며 전투 영역을 덮는 큰 배너를 사용하지 않는다.
- 토스트는 하단 중앙에 표시하고, 정보·성공·위험 상태마다 테두리와 아이콘 색을 바꾼다.

## 4. 전장 오브젝트

- 방 바닥은 생성한 `ward-floor-tile.png` 한 장에 얕은 외곽 단차와 마모를 담고, 스테이지 테마 색상을 곱해 사용한다. 중앙 사각형을 여러 겹 쌓는 지오메트리는 사용하지 않는다.
- 복도는 방보다 어둡게 하되 이동 가능 영역임을 알 수 있는 미세한 청색 패턴을 둔다.
- 방 외곽 한 타일 벽과 맵 테두리를 제외한 내부는 모두 연결된 복도다. 이동 경로 중간의 단독 벽·막다른 장식 벽은 생성하지 않는다.
- 벽은 테두리가 없는 `ward-wall-surface.png`를 사용해 개별 벽돌이 강하게 보이지 않고 하나의 매끄러운 방벽처럼 이어 보이게 한다.
- 문은 벽 경계 타일 위에 낮게 누운 평면 패널로 표현해 방 안 타일을 가리지 않는다.
- 침대는 작은 매트리스 대신 청록 조명이 들어오는 수면 포드로 표현한다.
- 설비는 탑다운 전용 투명 PNG를 사용한다. 수호 포탑은 레벨 1~15에 따라 포신·장갑·발광 코어가 **서로 다른 실루엣**으로 강화되고, 발전기·문 수리대·별고리 코일·새벽 보호막·월광 보석·사거리 증폭기도 강화 단계별 이미지를 사용한다. 그림자 덫 이미지는 더 이상 사용하지 않는다.
- 방 바닥·복도·벽은 서로 다른 명도·색조의 타일 텍스처와 음영으로 명확히 구분한다. 건설 가능한 빈 방 타일은 중앙 `+` 아이콘만 은은하게 펄스한다.
- 문은 1~10레벨에서 나무 문, 녹슨 강철문, 빛바랜 강철문, 빨간 강철문, 단단한 철창, 빛나는 철창, 강철 티타늄, 은빛 티타늄, 금빛 티타늄, 다이아 티타늄 재질을 사용한다. 11~15레벨은 현재 다이아 티타늄 외형을 유지한다. 전용 소재 PNG가 준비되면 이 다섯 단계를 별도 외형으로 분리한다.
- 문 레벨이 올라가도 크기가 벽과 겹치지 않도록 시각 스케일 증가는 최대 32%로 제한한다.

## 5. 전투 피드백

- 수호 포탑의 단일 포열은 기본적으로 자기 방의 문을 향한다. 귀신이 실제 공격 사거리 안에 들어오면 포열만 부드럽게 귀신 방향으로 회전하고, 사거리를 벗어나면 문 방향으로 돌아간다. 발사체는 포탑에서 귀신까지 실제로 이동해야 한다.
- 피격 시 귀신의 색상 플래시, 체력 바 감소, 짧은 충격 파티클을 동시에 표시한다.
- 문에는 현재 HP와 최대 HP를 나타내는 게이지와 숫자를 항상 표시한다.
- 문의 긴 축은 방 경계 방향을 계산해 상하·좌우 출입구에 맞춘다.
- 비점유 방은 평면 문 패널을 옆으로 줄여 열린 상태로 보이고, 침대 점유 후 중앙으로 펼쳐 닫는다. 파괴된 패널은 다시 표시하지 않는다.
- 다음 레벨 비용을 지불할 수 있는 건물만 건물 중앙에 겹치는 작은 노란 원형 테두리와 굵은 위쪽 화살표를 표시한다. 비용이 부족하거나 최대 레벨이면 화살표 자체를 숨긴다.
- 귀신이 HP 20% 이하에서 후퇴하면 이동 방향 표시와 후퇴 상태 라벨을 함께 표시한다.
- 문 파괴, 플레이어 사망, 귀신 처치처럼 결과가 바뀌는 사건은 화면 흔들림과 색상 플래시를 짧게 사용하되 반복 공격에는 남용하지 않는다.
- 침대 골드가 정수 단위로 증가하면 침대 위에서 금색 `◆ +n` 피드백이 떠오른다. 이 값은 해당 침대의 생산량만 표시하며, 무덤·랜덤 보상·캐릭터 특성 골드는 각각 자기 생산원에서 별도 표시한다. 반복 자원 문구는 WebGL 텍스처를 매번 생성하지 않고 화면 위 단일 HUD 캔버스에 투영해 벽이나 캐릭터에 눌리지 않게 한다.
- 발전기 또는 아이템 전력이 정수 단위로 증가하면 대표 발전기 위에서 청록색 `⚡ +n` 피드백이 떠오른다.
- HUD 자원 문구는 둥근 배경과 상승·페이드 애니메이션을 유지하되 동시에 최대 24개까지만 보관한다.

## 6. 카메라·터치·이동감

- 침대 점유 전에는 카메라가 플레이어를 따라가며 드래그 입력을 받지 않는다.
- 침대를 점유한 순간부터 카메라 추적을 해제하고 한 손가락 드래그로 자유 이동할 수 있게 한다.
- 귀신에게 잡혀 사망하면 캐릭터는 옆으로 쓰러지는 모션으로 전환하고, 침대 점유 여부와 관계없이 카메라 자동 추적을 해제해 관전 이동을 허용한다.
- 카메라는 북쪽이 화면 위로 오는 수직 직교 시점으로 고정하고 회전하지 않는다.
- 세로 기본 시야는 가로 약 8.4타일을 보여 방 전체와 주변 동선을 함께 확인하게 한다.
- 확대는 기본 대비 최대 1.5배, 축소는 기본 대비 최대 2배인 `0.5×~1.5×` 범위로 제한한다.
- 모바일은 두 손가락 핀치와 하단 `− / +` 버튼으로 확대·축소한다. 비틀기와 회전 버튼은 제공하지 않는다.
- PC는 마우스 휠로 확대·축소하고 좌·우 드래그로 카메라를 평행 이동한다.
- 조이스틱 지름은 약 120px, 주요 터치 목표는 최소 48px을 유지한다.
- 세로 화면에서는 조이스틱을 숨긴다. 침대를 점유하기 전에는 전장 어디든 터치한 지점을 이동 조작의 시작점으로 삼고, 그 상태에서 드래그한 방향과 거리를 월드 이동 벡터와 입력 세기로 변환한다. 단순 탭만으로 캐릭터가 이동해서는 안 되며 손을 떼거나 취소하면 즉시 정지한다.
- 세로 화면 좌측 상단에는 현재 캐릭터 얼굴 버튼을 표시한다. 버튼을 누르면 침대 점유 후 자유 카메라 상태에서도 내 캐릭터 위치를 다시 카메라 중심으로 이동시킨다.
- 침대를 점유하기 전에는 고정 침대 버튼을 노출하지 않는다. 빈 침대의 상호작용 범위에 들어오면 침대 옆에 `잠자기` 버튼을 투영하고, 범위를 벗어나거나 점유하면 즉시 숨긴다.
- 플레이어와 귀신의 방향 회전은 `+180°/-180°` 경계에서도 최단 각도 차이로 보간한다. 조이스틱을 360° 돌릴 때 경계에서 반대 방향으로 되감기지 않아야 한다.
- 플레이어 기본 속도는 초당 6.24타일, 기본 귀신 속도는 초당 3.55타일로 설정해 이동 대기 시간을 줄인다. 봇은 기존 기본 속도인 초당 4.8타일을 유지하되 같은 등급 보정을 적용하며, 고속 경로 갱신에서 직전 타일로 한 프레임 되돌아가지 않도록 다음 경로 타일을 선택한다.
- 준비 카운트다운이 시작될 때 50% 확률로 5~7개의 랜덤 보상이 복도 위에서 3초 동안 떨어진다. 착지한 보상 근처에서는 침대 버튼 자리에 `줍기`가 나타나며, 생존자는 한 개를 머리 위에 들고 이동한다. 빈 침대를 점유하면 그 보상은 점유한 방의 임의 빈 건설 타일에 배치된다. 골드·전력 생산형 보상이 대부분을 차지한다.
- 빈 타일 터치는 전역 300ms, 같은 타일은 520ms 동안 다시 선택되지 않는다. 설치를 시작하면 해당 패널의 모든 설비 버튼을 잠그고, 클라이언트와 서버가 각각 350ms 설치 입력 제한을 적용해 다른 설비가 연속 설치되는 것을 막는다.
- 이동 중인 내 캐릭터는 로컬에서 즉시 예측한다. 클라이언트가 보낸 아날로그 입력 세기는 서버도 정규화하지 않고 그대로 사용해 저강도 입력에서 서버만 전속력으로 앞서가지 않게 한다.
- 서버 위치 오차가 0.9타일을 넘을 때만 완만하게 보정하고, 1.5타일 이상의 큰 오차는 빠르게 보정한다. 한 렌더 프레임의 보정 이동은 최대 0.18타일이며 모든 보정에도 벽 충돌을 적용해 스냅 이동을 방지한다.
- 방 점유 상태는 이동 충돌 토폴로지를 바꾸지 않는다. 봇이 침대를 점유해도 진행 중인 드래그를 중단하거나 로컬 캐릭터를 즉시 서버 좌표로 옮기지 않는다.
- 서버는 초당 20회 이동을 계산하고 초당 10회 스냅샷을 일정한 누적 주기로 전송한다. 이동 입력 자체에는 즉시 전체 스냅샷을 재방송하지 않아 불필요한 렌더 갱신을 줄인다.
- 클라이언트가 사용하지 않는 귀신 A* 경로 노드는 전송용 스냅샷에서 제외한다. 서버는 건물·방·소유자 상태를 틱마다 한 번 인덱싱하고, 클라이언트도 건물별 전체 목록 재검색을 하지 않아 설비와 미니미가 늘어날 때 처리량이 제곱으로 커지지 않게 한다.
- 언데드 미니미는 개별 동적 조명을 만들지 않는다. 제거되거나 레벨 외형이 교체된 액터의 캔버스 라벨·지오메트리·머티리얼은 즉시 해제해 장시간 플레이의 GPU 메모리 누적을 막는다.
- 플레이어와 귀신의 한 프레임 이동량을 최대 0.12타일 단위로 나누고 서버·클라이언트가 같은 원형 충돌 반경을 사용한다. 지연이나 프레임 드롭이 있어도 벽 타일을 건너뛸 수 없다.

## 7. 진입 흐름과 게임 홈

1. 최초 실행 시 6.7초 길이의 복도 추격 티저를 표시한다. 사용자는 우측 상단 `건너뛰기`로 즉시 종료할 수 있다.
2. 티저는 브라우저 프로필의 `openingSeen`에 기록해 최초 한 번만 자동 재생한다. E2E 모드에서는 재생하지 않는다.
3. 로그인된 사용자는 세로 병원 복도, 계정·등급·포인트, 우편함 진입점이 있는 게임 홈으로 이동한다. 우편함은 서버 전체·개인·보상 우편을 계정별 읽음/수령 상태로 표시하고 읽지 않은 우편이 있으면 빨간 점을 표시한다. 홈 프로필의 등급 문구와 배지는 현재 선택한 `혼자하기 / 친구랑하기 / 랭크전` 기준으로 바뀌며 높은 일반 진행 등급을 고정 표시하지 않는다. 홈에는 현재 장착한 2.5D 캐릭터만 하단 중앙에 표시한다. 캐릭터는 사용자를 향한 정면 스프라이트로, 몸통을 흔들지 않고 두 발만 천천히 교대하는 제자리 보행을 반복한다. 귀신 추격 연출과 화면을 가로지르는 이동은 사용하지 않으며, 화면 비율이 달라도 귀와 발이 프리뷰 영역에서 잘리지 않아야 한다.
4. 홈 하단은 코드로 직접 그린 대형 SVG 아이콘 세 개로 구성한다. 화면에는 텍스트 라벨을 노출하지 않되 각 버튼의 접근성 이름은 `상점 / 스테이지 / 커스텀`으로 유지한다. 스테이지 영역의 좌측 플레이 방식 상자는 혼자하기·친구랑하기·랭크전 선택 모달을 연다. 우측 주 행동 버튼은 일반 모드에서는 현재 스테이지로 방을 만들고, 랭크전에서는 활성 계약 목록 또는 선택한 계약 대기실로 이동한다.
5. 로그인 화면도 같은 병동 배경을 사용해 인증 화면과 게임 홈이 하나의 세계처럼 이어지게 한다.
6. 대기실은 `새벽조 편성` 화면으로 구성하고, 룸 코드·참가자·스테이지 HP/공격 배율·맵 규칙을 한 화면에서 확인한다.
7. 결과 화면은 생존 시간, 귀신 레벨, 스테이지, 포인트 보상을 분리한 `NIGHT REPORT` 카드로 표시한다.
8. PWA 화면 방향은 `any`로 선언하고 세로 회전 차단 오버레이를 사용하지 않는다. 홈·로비·커스텀·상점·전장은 390×844와 844×390 모두에서 조작 가능해야 한다.
9. 홈에서는 `심야 병동` 제목과 별도 나가기 버튼을 노출하지 않는다. 포인트는 가로·세로 모두 계정 카드와 같은 상단 행에 두고, 로그아웃은 설정 모달 안에서만 제공한다. 프로필 카드 옆의 세로형 빠른 메뉴는 위에서부터 확성기(업데이트 내역), 광고 제거 예정, 순위대(랭크 순위표) 아이콘으로 구성한다. 확성기에는 별도 `업데이트 내역` 텍스트를 노출하지 않는다. 현재 스테이지 카드는 버튼으로 동작해 홈을 벗어나지 않고 해금된 난이도를 선택할 수 있어야 한다.
10. 세로 인게임의 설정 버튼은 우측 상단, 연결 핑은 그 왼쪽에 둔다. 침대 점유 전에는 침대 아이콘만, 점유 후에는 그 자리에 가방 아이콘만 표시하며 텍스트 라벨은 접근성 이름으로만 유지한다.
11. 세로 홈의 스테이지 요약은 보조 설명을 두 줄까지 자연스럽게 줄바꿈하며 말줄임으로 자르지 않는다. 세로 대기실은 접속자 목록이 컨테이너 너비를 사용하고, `선택 스테이지` 카드의 단계명은 카드 중앙에 정렬한다. 생존자 카드는 60px 높이의 컴팩트 행으로 표시하며, 상태색 원 대신 해당 플레이어의 프로필 사진을 표시한다.
12. 세로 인게임의 다른 생존자 얼굴 행은 골드·전력 아래에서 화면 안전 여백 전체 폭을 사용한다. 준비 시간에는 화면 중앙보다 약간 위에 남은 초를 큰 적색 숫자로 표시한다.
13. 홈, 대기실, 생존자 명단, 인게임 HUD의 프로필 원형 이미지는 같은 계정 사진을 사용한다. 사진을 등록하지 않은 플레이어는 캐릭터 동물 얼굴 대신 공통 기본 프로필 이미지를 사용한다.
14. Android 브라우저가 `데스크톱 사이트` 호환 모드로 980px 가상 viewport를 강제하더라도, 터치 가능한 세로 화면은 390px 논리 viewport로 정규화한다. 세로 레이아웃 분기는 폭 상한이 아니라 `orientation: portrait`를 기준으로 하며 일반 데스크톱 포인터에는 이 보정을 적용하지 않는다.

| 일반 진행 등급 | 배지 방향 |

- 등급 배지와 칭호 왕관은 이미지 텍스처로 렌더링하며 캐릭터 본체에 모자처럼 자동 합성하지 않는다.
- 구체적인 14일 시즌과 보상 규칙은 `docs/spec/ranked-mode.md`를 따른다.

## 10. 귀신과 생성 이미지 자산

- `opening-chase.webp`: 플레이어가 세 귀신에게 쫓기는 16:9 시네마틱 티저 배경이다.
- `dorm-home.webp`: 로그인·모드 선택에 사용하는 16:9 병동 전경 배경이다.
- `home-hospital-corridor.png`: 게임 홈에서 현재 장착 캐릭터를 보여 주는 세로 병원 복도 배경이다.
- `ghost-roster.webp`: 기본형, 질주귀, 거구, 봉인술사, 쌍둥이 A/B를 담은 초기 6종 콘셉트 시트다.
- `public/assets/sprites`에는 생존자 12종과 본체 귀신 11종의 투명 PNG 콘셉트·이동·공격 프레임이 있다.
- 생존자는 정면·후면·우측 방향별 대기 1장과 걷기 3장을 사용한다. 귀신은 같은 이동 프레임에 방향별 준비·타격·회복 공격 프레임 3장을 추가한다. 왼쪽은 우측 프레임을 수평 반전한다.
- 문틈 도약귀는 청록 포털 고리, 언데드는 녹색 병원복과 독성 발광, 거대 귀신은 큰 검은 연기 체형과 청록 눈으로 구분한다. 웃는 해체귀는 검은 눈구멍과 넓은 이빨, 전기톱, 붉은 마나 탱크로 구분한다. 오염 도배귀는 갈라진 창백한 얼굴, 검은 눈구멍, 보랏빛 도배복, 형광 연두 풀 롤러와 말린 벽지로 구분한다. 언데드 미니미는 11종 본체 수에 포함하지 않는 0.42배 소환체다.
- 인게임과 캐릭터 상점은 같은 아틀라스 프레임을 사용한다. `front / back / side` 버튼은 대기 프레임을 전환한다. 인게임 이동은 대기 프레임 사이에 좌·우 발걸음 프레임만 느리게 교대해, 몸통이 좌우로 흔들리거나 뛰는 것처럼 보이지 않게 한다.
- 구매 외형은 모자·옷·신발·장신구를 런타임 합성하지 않는 완성형 세트 스킨이다. 각 스킨이 앞·옆·뒤·걷기·수면 프레임 전체를 보유하며 홈·상점·커스텀·인게임에서 같은 완성 프레임을 사용한다.
- 서버의 이동·충돌·공격 판정은 기존 좌표계를 유지한다. Three.js 본체 모델은 포탑 미리보기 등 별도 3D 오브젝트에만 남긴다.
- 모든 생성 이미지는 이 프로젝트용 원본 프롬프트로 만든 독자 디자인이며 다른 게임의 캐릭터나 화면을 복제하지 않는다.

## 11. 구현 원칙

- 다른 게임의 이미지, 아이콘, 캐릭터 실루엣을 복제하지 않는다. 장르의 정보 구조와 밸런스 원칙만 참고한다.
- DOM UI는 `styles.css`의 공통 색상과 패널 규칙을 사용하고, Three.js 재질과 조명도 같은 색상 계열을 사용한다.
- 서버 이동·충돌·A\* 경로는 기존 직교 타일 좌표를 유지한다. 판정계를 교체하지 않고 Three.js 직교 렌더링으로 표시만 수직 2D로 바꿔 멀티플레이 동기화 안정성을 보존한다.
- 새로운 설비나 귀신 변종을 추가할 때는 흑백 실루엣만 보아도 기존 종류와 구별되어야 한다.
- 모바일 가로 화면 844×390을 최소 검증 해상도로 삼고, HUD와 행동 버튼이 플레이 공간을 과도하게 가리지 않는지 확인한다.
- 벽 본체와 상단 캡은 수직 시점에서 한 타일 안에 정확히 들어오게 해 방 안 타일 터치 영역을 침범하지 않는다.

## 12. 성능 안전형 전투 생동감

- 귀신 피격은 짧은 색상 플래시와 스쿼시, 문 피격은 작은 충격 흔들림과 풀링된 먼지, 포탑 발사는 포열 반동으로 표현한다.
- 발전기처럼 실제로 동작 중인 일부 설비만 아주 약한 호흡 펄스를 사용한다. 모든 건물에 상시 애니메이션을 걸지 않는다.
- 투사체와 먼지는 오브젝트 풀을 재사용하고, 동시에 보이는 효과는 고성능 72개·균형 40개·저성능 20개로 제한한다.
- 포탑 발사 연출은 품질 단계에 따라 최소 55ms·95ms·150ms 간격으로 합치며, 화면 밖 효과는 생성하지 않는다. 같은 10Hz 네트워크 프레임 안에서 한 포탑이 여러 번 발사해도 최신 연출 이벤트 하나만 전송한다.
- 평균 프레임 시간이 길어지면 충돌·피해 판정과 무관한 충격 링, 광원 글로우, 물보라부터 줄인다. 전투 시작 시 정한 DPR은 경기 종료까지 고정하며, 부하가 커져도 타일·건물 이미지 해상도를 낮추지 않는다.
- 모바일에서는 정적 이미지에 이미 포함된 명암을 사용하고 별도 실시간 그림자 패스를 끈다. 데스크톱에서는 기존 그림자 표현을 유지한다.
- 동일한 환경·타일 스킨 URL은 GPU 텍스처 하나를 공유한다. 타일 설치 전환 중에만 개별 타일 메시를 사용하고, 전환 완료 후에는 방당 단일 인스턴스 메시로 합쳐 드로우콜이 건물 수와 함께 계속 증가하지 않게 한다.
- 건물·포탑 원화 텍스처는 인게임·상점 미리보기가 같은 참조 카운트 캐시를 공유한다. 사용 중 텍스처는 폐기하지 않고, 미사용 텍스처는 최근 12개만 유지해 15단계 포탑 스킨을 반복해서 보더라도 GPU 메모리가 계속 증가하지 않게 한다.
- 빈 설치 타일 목록은 건물 또는 점유 방이 바뀔 때만 다시 계산하고, 매 프레임에는 이미 추린 표시만 펄스 애니메이션한다.
- 스냅샷 JSON 파싱은 Web Worker에서 수행한다. 느린 연결에서 송수신 버퍼가 한도를 넘으면 대체 가능한 이전 이동·스냅샷만 버리고 다음 최신 권위 상태를 받아, 메인 스레드와 네트워크 큐가 함께 밀리지 않게 한다.
- 버전이 붙은 이미지·스프라이트는 서비스 워커의 별도 정적 자산 캐시에서 즉시 읽고 백그라운드에서 갱신한다. 업데이트 확인 시 기존 캐시를 삭제하는 강력 새로고침 흐름은 유지한다.
- `prefers-reduced-motion`에서는 위험 비네트와 반복 펄스를 정지해 접근성과 GPU 사용량을 함께 보호한다.
