# 캐릭터 스킨, 포탑, 타일, 캐릭터 이미지 생성 규칙

## 공통

- 모든 이미지는 가운데 정렬한다.


## 캐릭터

- 캐릭터와 스킨 이미지를 생성할 경우 이동모션, 앉아있는 모션, 앉은 상태로 하품하는 모션, 잠자는 모션을 같이 만든다.
- 모든 캐릭터 이미지는 /public/assets/paperdoll/bases/character-bunny 를 기준으로 한다.


## 캐릭터 스킨

- 캐릭터와 스킨 이미지를 생성할 경우 이동모션, 앉아있는 모션, 앉은 상태로 하품하는 모션, 잠자는 모션을 같이 만든다.
- 프리미엄 스킨은 미리보기에서 보일 테마에 맞는 배경을 함께 제작한다.
- 이동모션시 이미지에서 몸 정렬은 같고 다리만 앞뒤로 움직이게해 몸이 좌우로 흔들리지 않게 한다.
- 이동모션시 모든 방향은 얼굴이 향하는 쪽이 기준이다. 
- 모든 스킨 이미지는 /public/assets/paperdoll/bases/character-bunny 를 기준으로 한다.


## 포탑 스킨

- 포탑 스킨은 1레벨부터 17레벨까지 총 17개의 이미지를 제작한다.
- 포탑 스킨은 1레벨부터 17레벨까지 진화하는듯한 외형을 가지며 레벨별 외형은 모두 달라야 한다.
- 포탑 스킨 이미지 크기는 /public/assets/turret-skins/skin-lifeguard-parasol 에 있는 파라솔 포탑 스킨을 참고해서 제작한다.
- 포탑 스킨 이미지의 포열은 무조건 아래를 탑다운 형식으로 바라보게 제작한다.
- 포탑 스킨의 포열은 무조건 1개다.
