# 친구, 채팅, 초대 및 빠른 문구

## 1. 범위

- 홈 상단의 친구 아이콘은 친구 목록, 1:1 채팅, 받은 방 초대를 연다.
- 친구랑하기 대기실에서는 친구 목록에서 현재 방으로 초대할 수 있다.
- 인게임에서는 전투 집중도를 유지하기 위해 자유 채팅 대신 정해진 빠른 문구만 전송한다.
- 랭크전 대기열과 진행 중인 게임에는 친구 초대 기능을 노출하지 않는다.

## 2. 친구

- 계정마다 자동 생성된 `FD-XXXXXXXX` 친구 코드를 가진다.
- 친구 코드는 대소문자를 구분하지 않고, 자기 자신·중복 친구·이미 대기 중인 요청은 거절한다.
- 친구 수는 최대 100명이다.
- 친구 요청은 계정당 최근 24시간에 20회까지 가능하다. 받은 요청은 수락 또는 거절할 수 있고, 수락 뒤에는 양방향 친구가 된다.
- 친구 삭제는 즉시 양방향 관계와 대화 접근을 해제한다. 과거 DM은 보관하지 않는다.

## 3. 1:1 채팅과 읽음

- 친구끼리만 1:1 메시지를 보낼 수 있다.
- 메시지는 1~200자로 제한하고, 발신 계정 기준 5초에 5개까지 허용한다.
- 대화 화면을 열어 메시지를 읽으면 마지막 읽음 메시지 ID를 저장한다.
- 홈 친구 아이콘의 빨간 점은 읽지 않은 DM, 친구 요청, 유효한 방 초대 중 하나라도 있을 때 표시한다.
- 계정별 `SocialPresence` Durable Object는 새 DM·친구 요청·수락·초대 푸시만 전달한다. 영속 데이터와 권한 판정은 D1이 항상 기준이다.

## 4. 방 초대

- 친구랑하기의 대기실에서만 초대할 수 있다.
- 초대는 현재 방 코드와 함께 전송되고 5분 뒤 만료된다.
- 수락 시 방이 `LOBBY` 또는 `COUNTDOWN`이면 바로 연결한다. 이미 시작했거나 종료된 방은 수락할 수 없다.
- 방의 인원 제한·재접속 토큰·방장 권한은 기존 `GameRoom` 규칙을 그대로 따른다.

## 5. 인게임 빠른 문구

버튼을 누르면 다음 네 문구만 모든 같은 방 참가자에게 표시한다.

1. `문 위험!`
2. `포탑 강화해!`
3. `내가 끝낼게!`
4. `좋은 아이템 발견!`

- 한 플레이어는 1초에 한 번만 전송할 수 있다.
- 서버 `GameRoom`이 전달하며, 게임 스냅샷이나 영속 전적에는 저장하지 않는다.
- 봇은 빠른 문구를 전송하지 않는다.

## 6. 데이터와 배포

- D1 마이그레이션 `0012_social.sql`은 친구 코드, 친구 관계, DM, 읽음 위치, 방 초대를 생성한다.
- Worker에는 계정별 `SOCIAL_PRESENCE` Durable Object 바인딩과 SQLite migration v3가 필요하다.
- 소셜 API는 세션 인증이 필수이며, 다른 계정의 친구·DM·초대 데이터를 반환하지 않는다.
