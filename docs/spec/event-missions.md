## 1. 화면 흐름

- 홈의 공지사항 아이콘 바로 아래에 이벤트 이미지를 배치한다.
- 받을 보상이 있으면 이벤트 버튼 우측 상단에 빨간 점을 표시한다.
- 현재 일일·주간 진행도가 모두 0이고 받을 보상도 없으면 이벤트 버튼 옆에 흰색 `미션을 진행해보세요` 라벨을 표시한다.
- 이벤트 화면은 `출석보상 / 일일 미션 / 주간 미션` 탭으로 구성한다. 출석보상 탭 버튼은 다른 탭과 구분되는 흰색 버튼이다.
- 완료한 미션은 카드별 `받기`로 하나씩 수령하거나 하단 `보상 일괄수령`으로 두 탭의 모든 완료 보상을 한 번에 수령한다.

## 2. 초기 미션과 보상

| 주기 | 조건 | 보상 |
| --- | ---: | ---: |
| 일일 | 앱 접속 | 20P |
| 일일 | 스테이지 1회 클리어 | 50P |
| 일일 | 스테이지 2회 클리어 | 75P |
| 일일 | 스테이지 3회 클리어 | 100P |
| 일일 | 랭크전 1회 정상 완료 | 75P |
| 주간 | 월~일 중 5일 앱 접속 | 50P |
| 주간 | 스테이지 5회 클리어 | 100P |
| 주간 | 스테이지 10회 클리어 | 150P |
| 주간 | 스테이지 20회 클리어 | 200P |
| 주간 | 랭크전 5회 정상 완료 | 150P |

- 일일 미션은 한국 시간 매일 00:00, 주간 미션은 한국 시간 매주 월요일 00:00에 새 주기로 전환한다.
- 로그인은 버튼을 누른 횟수가 아니라 한국 시간 기준 하루 첫 인증 앱 접속을 1회로 기록한다. 자동 로그인이 유지된 사용자도 출석으로 인정하고 같은 날 재접속은 중복 집계하지 않는다.
- 듀토리얼을 제외한 혼자하기·친구랑하기·랭크전의 승리만 클리어 횟수로 인정한다.
- 랭크전 완료는 승패와 무관하게 결과가 서버에 새로 기록되고 이탈 판정이 아닌 경우만 인정한다.
- 단계별 미션은 누적 달성 방식이므로 하루 3회 클리어하면 일일 보상 총 225P를 받을 수 있다.
- 모든 일일·주간 미션을 빠짐없이 완료했을 때 주간 최대 미션 수입은 2,890P다.

## 3. 서버 판정과 중복 방지

- 진행도와 보상 수령 여부는 기기 저장소가 아니라 D1 계정 데이터로 관리한다.
- 클라이언트가 완료 여부나 지급 포인트를 제출하지 않는다. 서버가 현재 주기의 지표별 누적값과 고정된 미션 정의를 대조한다.
- `account_id + mission_id + period_key`를 기본키로 사용하고 `INSERT OR IGNORE`와 포인트 지급 트리거를 결합해 연속 탭·재요청에도 한 번만 지급한다.
- 클리어 진행도는 경기 결과의 멱등 기록이 새로 생성된 경우에만 증가한다. 재접속으로 같은 경기 결과가 다시 전송되어도 증가하지 않는다.
- 출석은 `account_id + KST day_key`, 랭크전은 기존 `match_id + account_id` 결과 기본키로 중복을 막는다.
- 이전 로컬 D1에 `clear_count` 스키마가 이미 적용된 경우, 로컬 스키마 부트스트랩이 기존 클리어 진행도를 `stage-clears` 지표로 보존하며 자동 변환한다. 50P 이상만 허용하던 기존 보상 제약도 20P 출석 보상을 허용하도록 함께 변환한다.

## 4. 포인트 경제 기준

- 미션은 자주 접속하는 플레이어에게 확실한 보상을 주되, 승리 전리품과 상점 구매를 대체하지 않는 보조 수급처로 둔다.
- 캐릭터는 900~4,400P, 일반 세트 스킨은 4,000P, 프리미엄 스킨은 8,000P, 테마 타일은 1,800P, 대표 포탑 스킨은 2,500P로 조정한다.
- 전술 보급품은 300~550P로 조정해 일일 미션 한 세트만으로 고급 보급품을 매일 반복 구매하기 어렵게 한다.

## 5. 후속 이벤트 탭 후보

아래 항목은 현재 구현 범위에 포함하지 않고 다음 확장 후보로 둔다.

1. `기간 한정 작전`: 특정 난이도, 특정 포탑군, 보급품 미사용 등 플레이 방식을 바꾸는 1~2주 규칙을 제공한다.
2. `협동 목표`: 전체 이용자의 귀신 처치·문 수리 횟수를 합산하고 단계별 커뮤니티 보상을 개방한다.
3. `도감 연구`: 귀신·건물·스킨 사용 기록을 채워 프로필 배경, 칭호, 입장 연출을 해금한다.
4. `복귀 지원`: 오랫동안 쉬었다가 돌아온 계정에 바로 전투력을 주기보다 임시 체험 스킨과 단계별 복귀 임무를 제공한다.

포인트 외 보상을 도입할 때는 포인트를 또 다른 이름으로 복제하지 않고 `프로필 배경`, `칭호`, `입장 연출`, `이모트`, `스킨 체험권`, `상점 할인권`, `랜덤 상자 선택권`처럼 사용처가 명확한 보상을 우선한다.

## 6. 30일 누적 출석 보상

- 달력 숫자는 실제 월 날짜가 아니라 계정의 서로 다른 접속일 누적 횟수 `1일 출석`부터 `30일 출석`까지를 뜻한다.
- 한국 시간 기준 같은 날 여러 번 접속해도 1회만 증가하며, 중간에 접속하지 않은 날이 있어도 누적 횟수는 초기화되지 않는다.
- 해금된 칸을 사용자가 직접 눌러 보상을 수령한다. `account_id + attendance_day` 기본키로 재요청·연속 탭 중복 지급을 막는다.
- 1~6회는 매회 100P, 7회는 구름강아지 몽, 8~13회는 매회 150P, 14회는 파도 타일을 지급한다.
- 15~20회는 매회 200P, 21회는 서퍼 물총포, 22~29회는 매회 250P, 30회는 서퍼 몽을 지급한다.
- 7·14·21회 특별 보상을 이미 보유한 계정은 해당 상품의 판매가만큼 포인트를 받는다.
- 서퍼 몽을 이미 보유한 계정은 동일한 2,500캐시 가격대 프리미엄 스킨 중 하나를 고르는 선택권을 받는다. 기반 캐릭터가 없어도 스킨은 먼저 보유할 수 있지만 기존 장착 검증에 따라 캐릭터 해금 전에는 장착할 수 없다.
- 받을 출석 보상이 하나라도 있으면 홈 이벤트 아이콘 우측 상단에 빨간 점을 표시한다.

## 7. 판별 생존 미션

- 튜토리얼과 봇을 제외한 생존자에게 경기 생성 시 서버가 고정 시드로 1~2개 선택 임무를 배정하고 마지막에 `클리어` 임무를 붙인다. 따라서 한 판에는 총 2~3개가 표시된다.
- 선택 후보는 설치, 업그레이드, 특정 레벨 도달, 골드·전력 사용, 랜덤 상자, 보급품, 무료 수리, 영혼 저장병 등 38종으로 구성한다.
- 침대를 점유하기 전에는 기존 초반 미니맵을 표시하고, 점유 후에는 같은 좌측 상단 위치에 접고 펼칠 수 있는 미션창을 표시한다.
- 각 조건의 판정과 진행도는 게임 Durable Object의 권위 상태에서만 갱신한다. 완료 항목은 초록색 체크로 바뀐다.
- 임무별 보상은 설치 같은 단순 조건 20P부터 고레벨 업그레이드 50P까지다.
- 선택 임무를 실패해도 경기 클리어나 기본 클리어 보상에는 영향을 주지 않는다.
- 완료한 임무 포인트는 승리 결과에만 합산해 D1 경기 보상에 저장한다. 패배·중도 이탈에는 지급하지 않으며 같은 `match_id + account_id` 결과가 재전송돼도 한 번만 기록한다.
