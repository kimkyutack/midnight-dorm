- 문서 버전: 3.0
- 기준일: 2026-08-07
- 상태: 전투형 보급품 13종 구현 완료
- 연관 코드: `src/shared/shopConsumables.ts`, `src/server/auth.ts`, `src/server/engine.ts`, `src/server/GameRoom.ts`, `src/client/main.ts`
- 데이터 이전: `migrations/0028_combat_supply_catalog.sql`

## 1. 설계 원칙

전술 보급품은 계정 포인트로 수량을 구매해 한 경기에서 위기 순간에 사용하는 소모품이다. 보급품의 역할은 **귀신 대응과 방어 전략**으로 한정한다.

1. 귀신 위치 노출, 빈 침대 경로 표시, 이동속도 증가, 추적 회피 효과는 사용하지 않는다.
2. 초당 자원 생산이나 영구 능력치는 랜덤 상자·건물·외형의 영역이며 전술 보급품에 넣지 않는다.
3. 보급품은 즉시 효과, 짧은 지속 효과 또는 다음 한 번의 공격 강화만 제공한다.
4. 랭크전은 서로 다른 보급품을 최대 3종 장착하고, 일반 모드는 보유한 모든 보급품을 사용할 수 있다.
5. 원혼 유도 송신기는 설치할 때 재고를 한 개 소모하며 한 판에 최대 2회 발동한다. 두 번째 발동 후 철거되고 같은 판에는 다시 설치할 수 없다.
6. 가격, 재고, 대상 유효성, 중복 사용과 효과 계산은 서버가 판정한다.

## 2. 구매·장착·소모 흐름

```text
포인트로 1개 또는 5개 구매
  → 구매 확인
  → 계정 재고 증가
  → 랭크전은 대기실에서 최대 3종 장착 / 일반 모드는 전체 보유품 활성화
  → 인게임에서 유효한 대상 선택
  → 서버가 효과 적용에 성공
  → 계정 재고 1개 차감
```

- 잘못된 대상, 취소, 네트워크 오류, 경기 종료로 사용되지 않은 보급품은 차감하지 않는다.
- 재전송된 같은 사용 요청은 서버 요청 식별자로 한 번만 처리한다.
- 방 효과는 사용한 플레이어가 점유한 방에만 적용한다.
- `building` 대상은 기본 포탑·황금 포탑·별고리 코일만 허용한다.

## 4. 기존 30종 재고 이전

기존 ID를 삭제해 재고를 잃게 하지 않고 가장 가까운 전투 역할로 합산한다.

| 새 보급품 | 이전되는 기존 ID |
| --- | --- |
| 섬광 충격탄 | `scout-flare`, `quiet-slippers`, `echo-lens` |
| 취약 표식탄 | `path-chalk`, `moon-compass`, `mist-cape` |
| 포탑 과충전제 | `adrenal-shot`, `sprint-candy` |
| 집중 사격 비콘 | `room-beacon`, `rescue-whistle` |
| 긴급 문 수리 키트 | `quick-mortar`, `repair-window`, `emergency-bedroll`, `patch-paste`, `rewind-clock` |
| 합금 경첩 지지대 | `hinge-brace`, `steel-rivet` |
| 절대 방호 봉인서 | `ward-seal`, `ice-seal` |
| 최후의 걸쇠 | `last-latch` |
| 집속 탄두 모듈 | `toolbelt-voucher`, `calibrator-key` |
| 고속 윤활 카트리지 | `turret-grease`, `pulse-solder`, `spare-gears`, `copper-coil` |

- 마이그레이션은 계정별 동일 새 ID 수량을 합산한 뒤 기존 JSON 재고를 교체한다.
- 서버는 마이그레이션 전 저장 데이터를 읽을 때도 같은 매핑으로 정규화한다.
- 장착 목록에 남은 기존 ID도 새 ID로 바꾸고 중복을 제거한다.

## 5. UI 규칙

- 상점은 `공격 / 문 방어 / 포탑 강화` 분류를 표시한다.
- 랭크전 대기실은 `내 아이템 장착`과 최대 3종 선택을, 일반 모드 대기실은 `보유 아이템 전체 사용`과 전체 보유품을 표시한다.
- 인게임에서는 별도 가방을 표시하지 않는다. 빈 타일 설치 모달의 `보급` 탭에는 랭크전에서 장착한 최대 3종 또는 일반 모드에서 보유한 모든 보급품을 표시한다.
- 원혼 유도 송신기는 내 방의 빈 설치 타일에 설치한다. 발동 버튼에는 남은 사용 횟수와 재충전 시간을 표시하며 귀신 리스폰 중에는 비활성화한다.
- 대기실에서 연 상점은 게임 스냅샷이 갱신되어도 닫히지 않으며, 뒤로 가면 같은 대기실로 돌아온다.
- 타일 대상은 게임 보드의 타일을, 문 대상은 내 방 문을, 포탑 대상은 강화할 포탑을 선택하라고 안내한다.
- 사용할 수 없는 대상은 선택 단계에서 비활성화하거나 서버 오류를 한국어 메시지로 표시한다.
- 카드 이미지는 모바일 세로 화면에서 잘리지 않도록 고정 비율 영역 중앙에 `contain`으로 표시한다.
- 지속 효과는 대상 문·포탑 또는 방에 짧은 전투 이펙트를 표시하되 반복 파티클을 무한 생성하지 않는다.
- 건물·보급품 카탈로그 이미지는 대기실 진입 때 한 번 선로딩하고 세션 동안 디코딩된 이미지를 재사용한다. iOS WebKit에서 설치·장착 모달을 다시 열 때마다 이미지를 재디코딩해 늦게 나타나는 현상을 막는다.

## 6. 랭크전 경계

- 시즌 보상으로 받은 보급품은 일반 계정 재고에 지급한다.
- 랭크 `대여` 계약은 섬광 충격탄, 긴급 문 수리 키트, 집속 탄두 모듈을 참가자에게 각 1개 제공하며 계정 재고를 차감하지 않는다.
- 랭크 `금지` 계약은 보급품 사용을 막는다.
- 랭크 `페널티` 계약은 개인 재고 사용 1회마다 계약 점수를 차감한다.
- 시즌 외형과 이전 시즌 순위 보유 여부가 새 시즌 전투 성능을 높이지 않게 한다.

## 7. 검증 기준

1. `SHOP_CONSUMABLES`는 정확히 13개이며 공격·문 방어가 각 4개, 포탑 강화·설치형을 포함한 공학 계열이 5개다.
2. 카탈로그 ID는 중복되지 않고 랜덤 상자 아이템과 별도 체계를 유지한다.
3. 범위 공격과 취약은 유효 반경의 살아 있는 귀신에게만 적용된다.
4. 문 회복은 최대 HP를 넘지 않으며, 방어·무적·최후 방어의 종료 시점은 서버 시간으로 계산한다.
5. 포탑 강화는 선택한 포탑 또는 사용자의 방에만 적용되고 시간이 끝나면 원래 능력치로 돌아온다.
6. 재고가 없거나 이미 사용한 보급품은 다시 사용할 수 없다.
7. 320px 안팎의 세로 화면에서도 이미지·설명·가격·버튼이 카드 경계를 넘지 않는다.
8. 일반 모드는 장착 목록과 무관하게 보유 보급품을 모두 사용할 수 있고, 랭크전은 장착한 최대 3종만 사용할 수 있다.
9. 원혼 유도 송신기는 리스폰 중 발동할 수 없고, 첫 발동 후 60초 동안 재사용할 수 없으며 두 번째 발동 후 사라지고 재설치할 수 없다.
