# 심야 병동 튜토리얼 가이드

## 1. 목적

처음 접속한 플레이어가 별도 외부 문서를 찾지 않아도 필요한 규칙을 확인할 수 있게 한다. 정보 아이콘은 홈 화면에만 두며, 누르면 인게임·플레이 방식·포인트·랭크전·타임어택 탭을 가진 생존 가이드를 연다.

## 2. 공통 진행

1. 복도를 따라 빈 방으로 이동한다.
2. 침대 가까이에서 잠자기를 눌러 방을 점유한다.
3. 침대 골드와 발전기 전기로 문·포탑·전략 건물을 설치한다.
4. 문이 무너지기 전에 귀신을 처치하고 스테이지를 클리어한다.

골드와 전기는 현재 게임 안에서만 쓰이며, 커스텀 포인트는 승리 후 계정에 영구 저장된다.

### 2.1 첫 생존 훈련

- 첫 승리 전 혼자하기는 사용자가 고른 스테이지 대신 별도 `첫 생존 훈련`에 진입한다.
- 서버는 실제 플레이어와 가까운 방을 예약하며 봇은 이 방을 점유하지 않는다.
- 안내 순서는 `침대 점유 → 포탑 설치 → 침대 Lv.2 → 문 Lv.2 → 포탑 Lv.2 → 귀신 퇴각 관찰 → 발전기 → 서리 스프레이 → 그물 → 처치`다.
- 현재 단계에 필요한 설치·업그레이드만 활성화하며 필요한 재화를 단계별로 지급한다.
- 귀신이 퇴각하면 3초간 정지한 화면에서 회색 HP와 리스폰 회복을 설명한다.
- 발전기 설치 단계에서는 전력 450을 지급해 서리 스프레이와 그물을 모두 체험하게 한다.
- 첫 승리 보상은 100P이며 결과 화면에서 전술 보급 상점 또는 쉬움 1로 바로 이동할 수 있다.
- 훈련 완료 전에는 출시 이벤트와 상점 유도 팝업을 표시하지 않는다.

## 3. 탭별 내용

- **인게임**: 화면 드래그 이동, 빈 `＋` 타일 설치, 업그레이드 화살표와 전략 건물의 역할을 설명한다.
- **플레이 방식**: 혼자하기(생존 봇), 친구랑하기(초대 코드 협동), 랭크전(4인 자동 대기열)을 구분한다.
- **포인트**: 승리 보상, 외형·전술 보급 구매, 판 안 자원과 영구 포인트의 차이를 설명한다.
- **랭크전**: 노말 5·일반 완료 10회의 참가 조건, Unranked/브론즈 대기 범위, 40초 봇 보충, 2주 시즌·상위 5개 계약 기록을 설명한다.
- **타임어택**: 악몽 이상 일반 스테이지의 이벤트 시작, 2초 안내·30초 준비·5분 제한, 오버타임 강화, 승리 보너스를 설명한다.

첫 랭크전은 별도의 5초 암전 안내를 표시하고 귀신 소개 포스터는 생략한다. 이후에는 계약 규칙에 따라 30초 준비 또는 타임어택 안내로 이어진다.
