# 심야 병동 튜토리얼 가이드

## 1. 목적

처음 접속한 플레이어가 별도 외부 문서를 찾지 않아도 필요한 규칙을 확인할 수 있게 한다. 정보 아이콘은 홈 화면에만 두며, 누르면 인게임·플레이 방식·포인트·랭크전·타임어택 탭을 가진 생존 가이드를 연다.

## 2. 공통 진행

1. 복도를 따라 빈 방으로 이동한다.
2. 침대 가까이에서 잠자기를 눌러 방을 점유한다.
3. 침대 골드와 발전기 전기로 문·포탑·전략 건물을 설치한다.
4. 문이 무너지기 전에 귀신을 처치하고 스테이지를 클리어한다.

골드와 전기는 현재 게임 안에서만 쓰이며, 커스텀 포인트는 승리 후 결과
화면에서 전리품을 수령하면 계정에 영구 저장된다.

### 2.1 첫 생존 훈련

- 일반 가입 또는 Google 가입을 마친 신규 계정은 홈을 거치지 않고 `첫 생존 훈련`에 자동 진입한다.
- 훈련 승리 후에만 `tutorial_completed`를 저장한다. 앱을 종료하거나 연결이 끊겨도 완료 전에는 다음 실행에서 훈련으로 다시 진입한다.
- 튜토리얼 도입 전에 이미 일반 게임 기록·XP·승리·해금 스테이지가 있는 계정은 완료 계정으로 이관한다.
- 훈련에는 봇을 넣지 않는다. 서버는 플레이어에게 가까운 세 방 중 하나를 무작위로 예약한다.
- 튜토리얼에서는 30초 준비 타이머를 표시하지 않으며 귀신은 마지막 전투 단계 전까지 정지한다.
- 첫 단계에는 목표 방과 침대로 향하는 화살표를 맵 위에 직접 표시하고, 플레이어와 목표가 함께 보이도록 카메라를 자동 배치한다. 이동 중에는 배율을 다시 계산하지 않으며 침대 점유 뒤에만 한 번 확대한다.
- 각 단계의 안내 섹션은 HUD의 골드·전력 표시 바로 아래에 고정한다.
- 침대·문·포탑 업그레이드 단계에서는 해당 설비가 화면 중앙에 오도록 카메라가 자동 이동하며, 클릭할 대상에 반복 애니메이션을 표시한다.
- 포탑·발전기·그물 설치 단계에서는 지정된 빈 타일만 선택할 수 있다. 포탑과 발전기는 골드 탭, 그물은 전력 탭을 자동 선택하고 튜토리얼 중에는 다른 탭으로 바꿀 수 없다.
- 튜토리얼 중에는 사용자가 카메라를 이동하거나 확대·축소할 수 없다.
- 그물 설치 후 카메라는 정지한 귀신을 2초간 보여준다. 이후 문과 포탑이 함께 보이도록 카메라를 한 단계 축소하고 `귀신이 움직입니다` 안내와 함께 전투를 시작한다.
- 완료 화면의 `홈으로 이동` 버튼은 단독 전체 너비 버튼으로 표시한다.
- 안내는 아래 여덟 단계를 서버가 순서대로 잠근다. 현재 단계가 아닌 건설·강화·철거·이동·랜덤 상자·전술 보급 사용은 거부한다.

  1. 방 안에 들어가 침대를 점유한다.
  2. 침대를 Lv.2로 업그레이드한다.
  3. 문을 Lv.2로 업그레이드한다.
  4. 수호 포탑을 설치한다.
  5. 수호 포탑을 Lv.2로 업그레이드한다.
  6. 달빛 발전기를 설치한다.
  7. 전력 250을 모아 봉쇄 그물 발사기를 설치한다.
  8. 그물에 걸린 귀신을 포탑의 다음 한 발로 처치한다.

- 시작 전력은 정확히 240이다. 달빛 발전기가 전력 10을 생산해야 그물을 설치할 수 있다.
- 귀신은 7단계를 마칠 때까지 정지한다. 그물이 발동하기 전에는 포탑 피해로 HP가 1 아래로 내려가지 않으며, 그물 발동 후 포탑 한 발로 처치할 수 있게 서버가 남은 HP를 조정한다.
- 첫 승리 보상은 100P이며 `듀토리얼을 완료했습니다` 모달에서 홈으로 이동한다.
- 출시 이벤트 팝업은 튜토리얼을 완료하고 홈에 도착한 뒤부터 활성화한다.

### 2.2 Google 신규 가입

- 웹·PWA·네이티브 로그인 화면 하단의 원형 Google 버튼에서 Google ID 토큰을 발급받아 서버가 Google 공개키로 검증한다.
- 새 Google 계정은 검증만으로 계정을 만들지 않는다. 15분 동안 유효한 일회성 가입 토큰을 발급하고 닉네임 입력 화면으로 이동한다.
- 가입완료 시 서버가 NFKC 정규화·2~12자 검사와 전체 계정 닉네임 중복 검사를 수행한다. 중복이면 계정과 세션을 만들지 않고 다른 닉네임을 안내한다.
- 닉네임이 확정된 뒤에 계정·Google 식별자·보안 세션을 한 트랜잭션으로 저장하고 첫 생존 훈련으로 이동한다.

## 3. 탭별 내용

- **인게임**: 화면 드래그 이동, 빈 `＋` 타일 설치, 업그레이드 화살표와 전략 건물의 역할을 설명한다.
- **플레이 방식**: 혼자하기(생존 봇), 친구랑하기(초대 코드 협동), 랭크전(4인 자동 대기열)을 구분한다.
- **포인트**: 승리 보상, 외형·전술 보급 구매, 판 안 자원과 영구 포인트의 차이를 설명한다.
- **랭크전**: 노말 5·일반 완료 10회의 참가 조건, Unranked/브론즈 대기 범위, 첫 5판 배치전 RP 2배 보정, 40초 봇 보충, 4주 시즌·상위 8개 계약 기록을 설명한다.
- **타임어택**: 악몽 이상 일반 스테이지의 이벤트 시작, 2초 안내·30초 준비·5분 제한, 오버타임 강화, 승리 보너스를 설명한다.

첫 랭크전은 별도의 5초 암전 안내를 표시하고 귀신 소개 포스터는 생략한다. 이후에는 계약 규칙에 따라 30초 준비 또는 타임어택 안내로 이어진다.
