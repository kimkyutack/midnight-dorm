# 심야 병동 튜토리얼 가이드

## 1. 목적

처음 접속한 플레이어가 별도 외부 문서를 찾지 않아도, 현재 화면에서 필요한 규칙을 바로 확인할 수 있게 한다. 홈 화면에는 `i` 정보 아이콘을 두고 누르면 같은 가이드 모달을 연다. 각 화면은 현재 문맥에 맞는 탭을 처음 선택한다.

| 화면                              | 처음 여는 탭 |
| --------------------------------- | ------------ |
| 일반 대기실 · 인게임              | 인게임       |
| 외형 상점 · 내 보관함 · 전술 보급 | 포인트       |
| 플레이 방식 선택                  | 플레이 방식  |
| 랭크 대기열                       | 랭크전       |
| 결과                              | 포인트       |

가이드 안에서는 어느 탭으로든 이동할 수 있다.

## 2. 공통 진행

1. 복도를 따라 빈 방으로 이동한다.
2. 침대 가까이에서 잠자기를 눌러 방을 점유한다.
3. 침대 골드와 발전기 전기로 문·포탑·전략 건물을 설치한다.
4. 문이 무너지기 전에 귀신을 처치하고 스테이지를 클리어한다.

골드와 전기는 현재 게임 안에서만 쓰이며, 커스텀 포인트는 승리 후 계정에 영구 저장된다.

## 3. 탭별 내용

- **인게임**: 화면 드래그 이동, 빈 `＋` 타일 설치, 업그레이드 화살표와 전략 건물의 역할을 설명한다.
- **플레이 방식**: 혼자하기(생존 봇), 친구랑하기(초대 코드 협동), 랭크전(4인 자동 대기열)을 구분한다.
- **포인트**: 승리 보상, 외형·전술 보급 구매, 판 안 자원과 영구 포인트의 차이를 설명한다.
- **랭크전**: 노말 5·일반 완료 10회의 참가 조건, Unranked/브론즈 대기 범위, 40초 봇 보충, 2주 시즌·상위 5개 계약 기록을 설명한다.
- **타임어택**: 악몽 이상 일반 스테이지의 이벤트 시작, 2초 안내·30초 준비·5분 제한, 오버타임 강화, 승리 보너스를 설명한다.

## 4. 이미지와 개인정보

가이드 장면은 실제 플레이어 화면을 캡처하지 않는다. `public/assets/tutorial/`의 익명 예시 일러스트만 사용하며, 플레이어 닉네임·프로필 사진·HUD·실제 방 코드는 표시하지 않는다. 모든 장면은 모바일 카드 크기에 맞춘 WebP로 제공한다.

| 파일                        | 용도                    |
| --------------------------- | ----------------------- |
| `room-defense-guide.webp`   | 기본 진행과 인게임 방어 |
| `ranked-coop-guide.webp`    | 친구 협동과 랭크전      |
| `rewards-points-guide.webp` | 포인트와 보상           |
| `time-attack-guide.webp`    | 타임어택과 오버타임     |
