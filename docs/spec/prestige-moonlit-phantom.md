# 월령 환영 여우 프레스티지

## 상품과 결제 경계

- 귀신구슬 1회 가격은 1,500원이다. 10회는 단순히 15,000원이며 구슬 확정 보너스가 없다.
- 구슬은 33회 이내 1개를 보장한다. 1회 비용은 135 캐시(상위 팩 기준 ₩1,500)이며, 구슬 10개의 최악 비용은 330회 · 44,550 캐시 · 약 ₩495,000이다.
- 기존 프리미엄 스킨은 귀신구슬 뽑기에서 제외한다. Google Play/App Store 영수증을 서버가 검증하는 IAP가 완성되기 전에는 결제 성공이나 상품 지급으로 간주하지 않는다.
- 중복 캐릭터·스킨·타일·포탑 스킨은 별도 보상표를 사용하지 않고 `COSMETIC_CATALOG`의 현재 포인트 판매가만큼 지급한다.
- 월령 패키지는 구슬 10개로 교환하며 프로필 이미지, 프로필 테두리, 이모티콘 4종 세트, 월령 환영 여우, 월령 여우불 타일, 월령 천호포의 6개 상품으로 구성한다.
- 프레스티지 스킨·타일·포탑 스킨은 포인트 상점 카탈로그에서 항상 제외한다. 패키지를 보유한 계정의 내 보관함에서만 노출하고 장착할 수 있다.
- 프로필 이미지는 프로필 설정에서 기본 이미지, 업로드 사진, 보유한 프레스티지 프로필 이미지 중 하나를 선택한다. 프레스티지 이미지는 해당 패키지를 보유한 계정에만 표시한다.

## 구슬 상점 UX

- 홈 화면의 `광고 제거` 바로 아래에 구슬 상점 진입 버튼을 둔다.
- 상점 첫 화면은 1회·10회 귀신구슬 뽑기와 확률 안내만 표시한다. 프레스티지 패키지 판매 영역은 섞지 않는다.
- 우측 상단 `구슬 교환` 버튼으로 별도 화면에 이동한다. 교환 화면 왼쪽에는 프레스티지 테마 목록을 두고, 선택한 테마의 대표 이미지와 구성품을 중앙에 표시한다.
- 구성품 버튼으로 프로필 이미지, 프로필 테두리, 이모티콘, 스킨, 타일, 포탑 스킨을 각각 미리 볼 수 있다. 월령 패키지는 여섯 구성품을 구슬 10개로 한 번에 교환한다.
- 1회와 10회 소환은 동일한 확률표를 사용하고 10회 보너스나 구슬 확정 보상은 추가하지 않는다.
- 소환 연출은 실시간 3D나 CSS 파티클을 사용하지 않는다. 12장의 원화가 들어 있는 단일 WebP 시트를 캔버스 타임라인으로 재생해 매번 0프레임부터 자동 시작한다. 처음 2초는 미세한 흔들림이 점차 빨라지고 5초 전후에 빛기둥, 월광 폭발, 보상 카드 순서로 개방한다.
- 연출 중 화면 어디든 누르면 즉시 결과로 이동하며 운영체제의 모션 감소 설정에서는 정지 포스터를 사용한다.
- 일반 소환 결과는 세로형 상점 카드 목록으로 표시하고 캐릭터·스킨·타일·포탑은 실제 상품 이미지를 함께 보여준다. `확인` 옆의 `1회/10회 더 뽑기`는 같은 횟수를 다시 결제·지급하되 소환 연출은 반복하지 않는다.
- 확률과 중복 보상은 소환 영역 우측 상단의 정보 버튼으로 연다. 상점 본문에는 확률표를 항상 펼쳐두지 않는다.
- 프레스티지 교환 성공 시에는 `월령의 각성` 전용 25.6초 획득 시네마틱을 재생한다. 일반 구슬 소환 연출과 자산·재생기를 분리해 서로의 로딩을 막지 않는다.
- Google Play/App Store 상품 승인과 서버 영수증 검증이 준비되기 전에는 구매 확인 모달에서 무료 구매로 안내하고 서버가 실제 보상을 지급한다. 스토어 연결 플래그가 켜지면 무료 지급 API는 즉시 거부한다.

## 월령의 각성 획득 시네마틱

- 하얀 초승달이 뜬 새벽 풀숲에서 매미 소리와 으스스한 인게임 BGM으로 시작한다.
- 일반 여우의 뒷모습과 풀숲으로 걸어가는 장면 뒤, 다섯 귀신이 나타나 접근한다. 놀란 여우가 미소 짓고 월령 환영 여우로 각성한다.
- 귀신의 공격을 점프·덤블링·백덤블링으로 피한 뒤 파란 여우불로 다섯 귀신을 차례로 소멸시킨다.
- 전투가 끝나면 얼굴로 서서히 다가가며 심호흡과 감은 눈을 보여준다. 마지막에는 한쪽 눈을 번쩍 뜨고 하얀 월광으로 화면을 채운다.
- 총 길이는 25.6초이며, 6개의 9:16 마스터 장면에 카메라 이동·교차 전환·각성 섬광·전투 충격·마지막 화이트아웃을 실시간으로 합성한다.
- 매미, 발걸음, 변신 상승음, 귀신 공격, 여우불 타격, 심호흡, 마지막 각성음을 하나의 22.05 kHz 모노 효과 트랙으로 사용한다. BGM은 기존 인게임 트랙을 재사용한다.
- 연출 중 화면 어디든 누르거나 Enter/Space를 누르면 즉시 획득 결과로 이동한다. 운영체제의 모션 감소 설정이 켜져 있으면 시네마틱을 건너뛴다.
- 결과의 여섯 구성품은 가로 스크롤 카드로 표시한다.

## 프레스티지 외형과 프로필 테두리

- 월령 환영 여우는 기본 여우의 등급 해금 여부와 관계없이 패키지를 보유하면 장착 상태가 유지된다.
- 홈 화면은 월령 전용 6프레임 앉기·하품 아틀라스를 사용하고, 상점·보관함 미리보기와 인게임은 전용 4방향 이동 시트를 사용한다.
- 전용 미리보기에는 월광 오라를, 인게임에는 주위 여우불과 최근 6칸 흔적을 표시한다.
- 월령 여우불 타일로 방을 점유하면 바닥뿐 아니라 해당 방 외곽의 벽 블록을 월령 석벽으로 교체하고, 최대 4개의 여우불 벽 장식을 배치한다. 문·충돌·방 소유 판정은 기존 맵 데이터를 그대로 사용한다.
- 프로필 테두리는 패키지 최초 교환 시 기본 장착한다. 이후 프로필 설정에서 해제한 경우에는 다시 자동 장착하지 않는다.

## 능력 적용 범위

- 랭크전과 술래잡기에서는 스킨 능력이 비활성화된다.
- 일반 혼자하기와 친구랑하기에서 포탑 피해 +120%, 공격속도 +50%, 공격 포탑 Lv.6 시작, 기본 포탑 Lv.17 상한을 적용한다.
- 이중 영혼 방어막은 방 최초 점유 때 문 최대 HP 30%짜리 두 겹을 한 판에 한 번만 부여한다. 피해로 사라진 겹은 문 업그레이드로 재생되지 않는다.
- 악몽 지배는 친구랑하기의 모든 귀신에게 이동속도 15% 감소를 비중첩 적용한다. 귀신 발밑의 청색 링과 `이동속도 감소` 문구는 서리 감속에도 공통 사용한다.

## 렌더링과 성능 상한

- 이동 여우불은 서버 이벤트를 추가하지 않고 기존 위치 스냅샷에서 타일 진입을 감지한다.
- 플레이어당 흔적은 최근 6칸, 주위 여우불은 2개로 고정한다. 만료 즉시 GPU 자원을 해제한다.
- 포탑 공격은 기존 레이저·충격파 오브젝트 풀을 재사용한다. 효과 품질에 따라 충격파를 1/2/3개로 제한한다.
- 방 외곽 연출은 하나의 `InstancedMesh`로 묶는다. 다른 방 바닥과 1칸 이내인 외곽 타일은 제외한다.
- 월령 석벽도 방당 하나의 `InstancedMesh`로만 추가하고, 벽 장식은 방당 4개 이하의 메시를 재사용한다. 벽 연출은 파티클이나 매 프레임 인스턴스 버퍼 갱신을 사용하지 않는다.
- D1 프로필 조회는 기존 `db.batch()`에 지갑·패키지·장착 정보 세 쿼리를 포함하고, 실시간 전투 상태는 GameRoom Durable Object 한 곳에서 판정한다.
- 시네마틱 런타임은 압축 WebP 6장과 약 1 MB 효과음만 배포한다. 생성 원본 `source/`는 빌드 후 정리하여 Cloudflare와 네이티브 번들에 포함하지 않는다.
